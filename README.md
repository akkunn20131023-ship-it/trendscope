# 🌍 TrendScope — 世界の面白ニュース収集 ＆ 釣りタイトル冷静判定

> 📁 構成: ローカル版（Python, `server.py` ほか）／公開版（`cloudflare/`）／自動収集（`.github/workflows/collect.yml` → `collect_public.py`）

APIキー不要・課金ゼロ・pip install 不要（Python標準ライブラリのみ）。

## 起動
- **Windows**: `start.bat` をダブルクリック
- **Mac**: `start.command` をダブルクリック（初回だけ右クリック→「開く」）
- 手動: `python server.py` → http://localhost:8000

初回は venv を自動作成し、ブラウザが自動で開きます。8000番が使用中なら 8001, 8002… を自動で使います。

## できること
- Reddit（TIL / interestingasfuck / UpliftingNews / technology / gaming）、Hacker News、ScienceDaily、BBC、Good News Network から自動収集
- Google翻訳の無料エンドポイントで日本語化（失敗時は MyMemory に自動切替）。翻訳結果は `data/translations.json` に永続キャッシュ
- ニュースは12分キャッシュ。裏で自動更新されるので、開いた瞬間に表示されます
- 釣り判定：煽りワード辞書（日英約60パターン）・記号の多用・大文字強調・絵文字・【】・寸止め構文を採点し ★1〜5
- URLを貼ると本文/YouTube説明欄/Xポストを取得し、**見出しと本文のギャップ**（重要語の一致率・数字の根拠・本文の温度差）も判定
- お気に入りは `data/favorites.json` に保存（ブラウザを変えても残る）

## データの場所
`data/` フォルダを消すとキャッシュとお気に入りがリセットされます。

## 🗺 世界マップ（v2）
画面上部の「🗺 世界マップ」から。すべて無料・登録不要のデータです。
| レイヤー | データ元 | 更新 |
|---|---|---|
| ニュースの話題地 | 収集ニュースの本文から国を推定 | 5分 |
| 情報の発信元→話題地 | 各メディアの所在地から線で表示 | 5分 |
| 紛争・対立地域 | 2026年11月時点の編集リスト＋GDELT（世界の報道DB）の直近3日の報道 | クリック時 |
| 飛行機 | adsb.lol（予備: airplanes.live / OpenSky） | 15秒 |
| 電車 | フィンランド鉄道 Digitraffic（全列車GPS）。日本は config.json に ODPT キーで東京メトロ・都営 | 20秒 |
| 地震 | USGS（24時間・M2.5以上） | 2分 |
| ISS | wheretheiss.at | 5秒 |

- 紛争地域をクリック → 概要・対立勢力・**どこの国のメディアが報じているか**・最新報道（日本語訳）
- 各ニュースの「📝 3行要約」→ 記事本文を読み込んで日本語で3行にまとめます
- 「📋 ダイジェスト」→ いまの世界を3行で／話題の国／キーワード／紛争関連報道／カテゴリ別ピックアップ

## 🧹 v6：画面整理・軽量化・安定化・ガイド・公開版
- **☰ メニュー**：設定・表示・ゲーム・公開サイト・使い方・ログ・アップデートを1か所に。「🧩 表示する機能を選ぶ」で使わないタブやボタンを隠せます
- **軽量化**：通信の圧縮（gzip）・変更がないファイルは再送しない（ETag）・画面が見えていない間は自動更新を止める
- **安定化**：通信エラーをまとめて通知、📜 動作ログ画面、⬆ zipファイルからのアップデート（データは消えず自動バックアップ）
- **ガイド**：初回起動時のツアー、❓ 使い方ガイド
- **🌍 公開版（GitHub ＋ Cloudflare Pages）**：誰でも見られる閲覧専用サイト。1時間ごとに GitHub Actions が自動更新。始め方は **CLOUDFLARE_GUIDE.md** を参照
